Available Build Packages & Installation Guide

Official Public Test Builds (PTB) are released periodically ahead of upcoming major seasons. These builds allow players to preview new content, maps, weapons, and features before they hit live global servers. Follow the step-by-step instructions below for your device.

Android Installation
  1. Select either the 32-bit or 64-bit download link. (Note: 64-bit is optimized for newer, high-performance hardware, while 32-bit is ideal for older devices).
  2. Wait for the APK file to download completely to your system storage.
  3. Open your device's File Manager, download manager, or notification panel, tap the downloaded file, and proceed to install the test application.
iOS (TestFlight) Installation
  1. Tap the TestFlight link to open Apple's secure testing portal. If prompted, download and install the official TestFlight app from the App Store.
  2. Once TestFlight is installed on your device, return and tap the test link again to load the installation prompt.
  3. Tap Install to get the test build.
    (Note: Apple caps slots at 10,000 testers; if full, check back when fresh slots open).
First Launch & Account Setup (Both Platforms)
  1. Launch the installed test app and choose to create a new account using the "Guest" login option.
  2. After setup finishes, complete the brief introductory tutorial sequence.
  3. Once the tutorial is complete, you will gain full access to the standard test lobby.
Download Troubleshooting Tip
  1. If a download freezes, encounters errors, or stalls inside a social media app, tap Copy Link instead.
  2. Open your device's primary web browser (such as Chrome or Safari) and paste the URL directly into the address bar.

Why? Heavy downloads frequently glitch inside in-app web views. Using a dedicated external browser is significantly more reliable.
